# 语音 + 摄像头联合辅助

## 使用

1. 保持 nRF USB 与 Mac Agent/bridge 运行，打开 http://127.0.0.1:8000 并刷新。
2. 打开摄像头，选择 LRCP G720P，确认预览内容。
3. 勾选“画面辅助任务”。此操作表示允许创建任务时将选中摄像头的最新画面及目标文字发送 SiliconFlow。
4. 若正在执行任务，长按 K1 松手返回待机；单击 K1 说目标，再单击结束。
5. 本地 Whisper 转文字；视觉模型描述相关场景；DeepSeek 综合生成动作；板子显示动作。网页显示本次画面参考。
6. 取消勾选或关闭摄像头即可停止画面辅助。已发出的云端请求无法撤回。

## 实际边界

这是实时预览加“最新单帧 + 语音转写”辅助，不是连续视频动作识别；不自动判定动作完成。原有 K1/K2 操作不变。摄像头、图片压缩在 Mac 浏览器，图片不经过 nRF，不增加板子图像处理负担。

浏览器每2秒将一帧JPEG（宽640）发到本机；后端只保留最新帧，8秒失效，下一次访问时清除。创建任务时取帧一次，不持续向云端上传。关页依赖清除请求/过期机制。页面保持前台，防止浏览器后台节流使帧过期。无有效画面时使用纯语音/文字流程。

原始图片不写入任务日志和磁盘；场景文字进入当前任务内存并显示网页，生成动作仍会进入普通事件记录。语音原始音频沿用本地 Whisper。密钥只存后端 `.env`。

## 接口增量

- POST `/api/camera/frame`：`{"image":"data:image/jpeg;base64,..."}`；有效JPEG，编码最多150万字符、尺寸最长边1280；返回 `ok,expires_in_seconds:8`。
- DELETE `/api/camera/frame`：清空本机最新画面，不撤销已发请求。
- GET `/api/state`：新增 `camera.fresh_frame`、`generating`；完成联合生成后新增 `visual_context`、`input_mode=voice_or_text+camera`。
- POST `/api/session/start`：目标字段不变，有新鲜画面时执行视觉描述再拆解。生成中重复创建/新建/恢复/撤回/反馈返回409。
- 模型失败返回502，无静默固定模板回退。桥接生成任务为异步等待，主循环继续维护心跳/显示。

目前最新画面是本机全局单份缓存，设计用于单用户单网页演示；不支持多用户隔离。语音/网页目标均可能使用最近启用页面上传的画面。

## 验证

43 项自动测试通过：图片验证、过期清理、场景与目标合并、图片不进入状态、生成失败释放忙状态、忙时禁止新建，以及已有语音/按键回归。摄像头640×480实际取帧已通过。浏览器真机权限、预览及真人语音联合流程仍需现场验收。

云端真实验证：`Qwen/Qwen3-VL-30B-A3B-Instruct` 约4.5秒正确描述合成红色方形，DeepSeek-V4-Flash据此生成对应步骤。原8B视觉模型连续超时，已替换。在线图片POST/DELETE均200并验证清除；设备0.7显示帧确认正常。
