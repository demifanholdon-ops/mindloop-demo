# MindLoop 0.7 操作说明

- 开机等待电脑 Agent 与硬件桥接；连接前按键不能开始语音。断线超过 8 秒显示等待连接，桥接每 2 秒重试。
- 待机：单击 K1 录音，再单击结束；最多录音 15 秒自动停止。存在暂存任务时长按 K2 恢复。
- 录音中：只接受 K1 单击停止；停止及识别中屏蔽所有按键。
- 任务中：单 K1 完成、双 K1 撤回一步、长 K1 暂存并新建；单 K2 缩小步骤、双 K2 换法。长 K2 无任务操作，会显示提示。
- 完成页：单 K1 新任务，单 K2 重做最后一步；其他手势给出不可用提示。
- 单击在松手后等待约 350ms；双击需在窗口内再次按下；长按至少 800ms、松手触发。
- 恢复任务只允许在待机/完成页，网页相应禁用按钮；只保留最近一份暂存任务，保存在 Agent 进程内，退出 Agent 后不保证恢复。
- 固件负责按键识别和显示；Mac 负责语音转写及任务状态。尚不支持脱离电脑独立使用。

验证：自动测试覆盖任务恢复、活动任务防覆盖、识别中重复按键及现有音频/桥接流程；实体屏幕、按键手感和真人语音仍需现场验收。

0.7 修复录音期间全局关中断导致的掉线风险；6/12/15 秒与并发显示采集测试通过。当前体验采用 nRF 直连 USB。
