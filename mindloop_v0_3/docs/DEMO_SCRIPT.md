# MindLoop 4-minute Demo Script

## 0:00–0:35 — Problem
用户不是不知道目标，而是“目标存在，但难以启动”。

## 0:35–1:35 — Task initiation
输入：
“我要准备明天的项目汇报，但现在不知道从哪里开始。”

系统只给一个原子动作。
点击 STUCK，动作进一步缩小。
点击 DONE，显示启动时延。

## 1:35–2:20 — Attention drift
触发 Drift。
可穿戴模拟器显示 double-soft haptic。
点击重新专注，显示 Return-to-task Time。

## 2:20–3:05 — Personalized closed loop
解释 DONE / STUCK / HELP 是训练个人启动策略的反馈信号。
目标不是提醒更多，而是用更少干预获得行动。

## 3:05–3:40 — EvoMap
展示去身份化 Gene + Capsule：
不上传原始音频、视频、精确位置或直接身份信息。
只共享验证过的策略和效果指标。

## 3:40–4:00 — Closing
“MindLoop 把 Agent 从屏幕里带到现实世界：它不只告诉你该做什么，而是帮助你真正开始。”
